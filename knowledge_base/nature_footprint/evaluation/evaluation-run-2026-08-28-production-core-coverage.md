## Remaining semantic failure

`SDS-03` returned an answer stating that detailed Audit Log events were not present, although the retrieved context supported them. The workflow reached and successfully executed `FINAL ANSWER COVERAGE CHECK`, but the upstream `required_answer_terms` list did not contain the omitted Audit Log events. Consequently, the deterministic checker had no missing term to detect.

This proves that deterministic string coverage is useful but not sufficient when its complete contract is generated by another stochastic LLM. The fix should not be a one-question `SDS-03` rule. Use a hybrid contract with typed deterministic anchors for exact schema identifiers, figure/table/section references, numeric values, and approved high-risk factual facets, unioned with evidence-generated terms.
