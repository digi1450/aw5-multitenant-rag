# Distributed workflow

The main distributed workflow is [`aw5-rag.yml`](aw5-rag.yml), a portable derivative of the owner baseline. It has no selected Knowledge Bases and requires setup; see [Dify instructions](../README.md).

This is a deployment template, not a byte-identical export of the owner's live Draft/Published app. Original exports and historical controls were moved to a local ignored backup during the owner-authorized portfolio cleanup on 2026-10-22. Their runtime/evaluation claims are not transferred to this template.

Import validation and fresh-install end-to-end behavior must be checked in the operator's own environment. No running Dify app was changed by preparing this file.
